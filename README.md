# running-sim

신체 치수와 근골격 특성을 직접 설정하고, 3D 외형과 달리기 조건별 반응을 비교하는 개인 러닝 시뮬레이션 프로젝트입니다. 이름은 임시입니다.

핵심 경험은 설정한 3D 러너가 실제 경로를 달리는 과정을 보는 것입니다. 첫 시범 코스는 김해 롯데가든파크 주변 트랙이며 주변 풍경은 구현하지 않습니다.

## 목표

- 키, 몸무게, 다리·상체 길이, 어깨너비, 발 크기 등 입력을 3D 외형에 반영합니다.
- 에너지 소모, 심박 반응, 피로, 10km·42.195km 완주 시간을 검증 가능한 범위에서 비교합니다.
- 논문에 근거한 계산과 공개 데이터 재현 실험을 통해 적용 범위와 오차를 제시합니다.
- 체형 조작과 시나리오 비교의 재미를 살리며, 시뮬레이션 경험을 웹·백엔드·클라우드 포트폴리오로 확장합니다.
