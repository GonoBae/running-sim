**사용자 확정 / 구현:** 직접 뛰어본 위치 설명에 맞춘 M91 배율을 철회하고, 원본 경로 수집·검증과 거리·도착점 계산을 자동화합니다. [화면·코드·검사](../05-validation/COURSE_AUTOMATION.md).

## M90 · 목표 페이스와 소요 시간

**사용자 확정 / 구현·검사 완료:** 목표 페이스를 코스 속도·소요 시간에 반영하며 기존 신체·자세·출발점·방향·거리를 유지합니다. [실제 화면·코드·검사](../05-validation/COURSE_PACE.md).

| 항목 | 이번 구현 계약 |
| --- | --- |
| 입력 | 기존 동작 속도 / 목표 페이스 선택 · 목표 1:00–30:00 분/km · 1초 단위 · 목표 활성화 초기값 6:00 |
| 보관 | 선택 필드 course.paceSecondsPerKm · 없는 기존 저장값은 기존 동작 속도 유지 · 다른 설정 보존 |
| 시간 | 속도 m/s = 1000 / 페이스 초 · 소요 초 = 총 m × 페이스 초 / 1000 · 경과 시간과 총 소요 시간 표시 |
| 동작 | 한 주기 전진 거리 유지 · 주기 시간만 목표 속도에 맞춤 · 같은 위상의 관절·발 방향·몸 높이·신체 비율 보존 |
| 배속 | 1/2/4×는 관찰용 재생 배속 · 설정 페이스·총 소요·도착 위치는 불변 |
| 도착 | 페이스 변경으로 지도 거리·도착 좌표를 바꾸지 않음 · 목표 거리에서 정지 |
| 오류 | 빈 입력·초 60 이상·범위 밖·소수 입력은 저장하지 않고 다음 차단 · 오류 종류별 복구 |
| 현장 차이 | 1–5km 제보 보존 · 사용자 3km B 이후/4km C 이후 확인 · 계산식 독립 검산 · 정확한 현장 대응점 확인 전 경로 길이 배율 변경 없음 |
| 해석 | 지정한 페이스를 계속 유지한다는 산술 결과 · 자세에 따른 실제 기록 예측 아님 · 속도별 자연스러운 보폭/케이던스 모델 미검증 |

출처: 사용자 ‘목표 페이스…주행 속도와 소요 시간…기존 설정 유지’, ‘실제로 뛰었을 때 거리와 도착점 차이’, 1–5km 구간별 설명, ‘3키로는 B / 4키로는 C’. **R03·R04·R08·R15 / D06 / SCR04·SCR05 / M89→M90**.
