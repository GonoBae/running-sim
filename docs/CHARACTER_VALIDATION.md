# 설정값에 따른 전신 캐릭터 조절 검증 계획

작성일: 2026-10-02

첫 검증의 질문은 입력한 신체 치수에 맞춰 사람 형태의 전신 캐릭터를 조절할 수 있는가이다. 사용자의 지적에 따라 트랙 주행과 좌우 동시 재생보다 먼저 수행한다. 현재는 검증 계획이며 캐릭터 에셋이나 조절 기능을 구현·검증한 것은 아니다.

## 검증 목표

정지 상태의 전신 캐릭터에서 설정값 변경, 외형과 관절 반영, 변형 후 치수 측정까지 연결한다. 외형이 달라 보이는 것만으로 통과시키지 않는다. 입력값과 모델에서 측정한 값이 일치하는지, 다른 부위에 의도하지 않은 변화가 생기는지 확인한다.

검증 결과로 지원 가능한 입력 항목과 조합, 한계, 모델 확보 또는 제작 방식을 결정한다. 달리기 동작은 그다음 단계에서 검증한다.

## 첫 검증 화면 제안

정지한 사람형 전신 캐릭터 한 명과 설정 패널을 표시한다. 앞·옆·뒤에서 살펴보고 관절과 측정 기준점을 켤 수 있게 한다. 입력 치수, 변형 후 측정 치수, 차이를 함께 표시하고 기본 체형으로 초기화할 수 있게 한다.

이 화면은 기술 검증용이며 결과를 별도의 [캐릭터 커스터마이징 화면](CUSTOMIZATION_SCREEN.md)에 연결한다. 사용자는 첫 접속에 이 커스터마이징을 먼저 진행한다. 승인한 좌우 주행 화면은 그다음 단계다. 트랙, 달리기, 로그인과 서버 저장은 체형 검증의 필수 항목이 아니다.

## 항목별 확인 내용

측정 기준과 변경 규칙은 모델을 선정한 뒤 확정한다. 표의 기준은 실험 설계를 위한 제안이다.

| 설정 | 확인할 변화 | 먼저 정할 기준 |
| --- | --- | --- |
| 키 | 기준 자세에서 발바닥부터 머리까지의 높이 | 신발 포함 여부, 기준 자세, 부위 길이와의 관계 |
| 다리 길이 | 지정한 기준점 사이의 길이와 골반·무릎·발목의 위치 | 측정법, 허벅지·종아리 비율, 키 유지 여부 |
| 상체 길이 | 지정한 몸통 기준점 사이의 길이 | 목·골반 기준, 키와 다리 길이의 관계 |
| 어깨너비 | 좌우 어깨 기준점 사이의 폭 | 관절 중심 간 거리인지 외형 폭인지 구분 |
| 발 크기 | 발뒤꿈치부터 발끝까지의 길이 | 맨발 기준인지 신발 외형 기준인지 구분 |
| 몸무게 | 수치 보관과 외형 대응 규칙을 구분 | 몸무게만으로 어떤 외형을 부여할지 미정. 임의로 몸통을 넓혀 정확한 체형이라고 표현하지 않음 |
| 근골격 특성 | 필요한 모델 정보와 후속 입력 정의 | 근육량·근력 등 변수의 의미와 외형·계산의 관계를 정한 뒤 별도 검증 |

키와 부위 길이의 관계를 먼저 정해야 한다. 키를 유지하면서 다리를 늘릴 때 어디를 줄일지, 그 조합을 허용하지 않을지 명시한다. 다른 입력값을 몰래 보정하지 않는다. 첫 실험에서는 한 항목씩 바꿔 함께 변하는 부위를 기록하고 입력 규칙을 선정한다.

## 검증 순서

1. 수정과 웹 배포가 허용된 전신 모델 후보의 관절 구조와 변형 가능한 부위를 확인한다.
2. 기준 자세, 단위와 측정점을 정하고 변형 전 치수를 기록한다.
3. 키·다리 길이·상체 길이·어깨너비·발 크기를 각각 변경한다.
4. 변형 후 치수를 측정해 입력값과 비교하고, 원래 값으로 복원되는지 확인한다.
5. 여러 값을 조합해 몸체의 틈새, 관통, 관절 이탈, 발바닥 높이와 복장 변형을 확인한다.
6. 편집 도구에서 가능한 변형을 웹에서도 같은 설정값으로 적용할 수 있는지 확인한다. 내보낸 모델이 조절 기능까지 자동 보존한다고 가정하지 않는다.
7. 지원 범위와 제약을 정한 뒤 달리기 동작, 좌우 동기화, 트랙 이동 순서로 검증한다.

기본값·지원 범위의 양끝·중간값을 포함하고, 키와 다리 길이처럼 연관된 항목은 조합해서 검사한다.

## 통과 기준과 산출물

| 기준 | 남길 증거 |
| --- | --- |
| 치수 일치 | 입력값·측정값·차이 표. 허용 오차는 측정 정의를 정한 뒤 실험 전에 수치로 고정 |
| 외형 유지 | 앞·옆·뒤 비교 이미지와 관통·틈새 여부 |
| 관절 일치 | 변형된 신체와 관절 위치가 맞는지 확인한 화면 |
| 변경 규칙 일관성 | 한 항목 변경 시 영향을 받는 다른 부위와 그 이유 |
| 재현 가능성 | 동일 입력으로 동일 치수를 얻고 기본값으로 복원되는지 확인 |
| 웹 반영 | 웹에서 입력 변경과 외형·관절 변화가 연결되는 화면 기록 |
| 이용 가능성 | 모델·복장 등 자료별 출처와 수정·배포 조건 |

항목별 결과는 가능, 조건부 가능, 미지원, 미검증으로 구분한다. 몸무게 저장만 구현하면 외형 반영까지 가능하다고 기록하지 않는다. 일부 치수만 지원할 수 있다면 요구를 축소해 확정하지 않고 한계와 대안을 제시한다.

필수 치수의 조절 가능성과 지원 범위가 확인되면 다음 단계로 진행한다. 실패 시 다른 모델, 변형 방식 또는 직접 제작을 검토한다. 달리기를 먼저 완성하고 체형 조절을 뒤로 미루지 않는다.
