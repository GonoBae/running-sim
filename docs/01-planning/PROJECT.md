| 캐릭터 | MakeHuman 사람형 전신 · 러닝에 필요한 설정 |
| 코스 | 김해 롯데가든파크 주변 트랙 · D 경로 좌표 확보·지도 거리 계산 · 현장 도착점 전체 일치 미해결 |
| 화면 | 왼쪽 트랙 / 오른쪽 같은 순간 자세 · 주변 풍경 제외 |
| 메인 | v2 방향 승인 → v3 상단 러너·코스 메뉴 제거 |
| 서비스 제외 | 자세 추천 · 교정 점수 |
| 배포 방향 | Vercel Pro · 운영 인증/게시/통계는 Supabase 연결 전 · 개인 저장 후속 · AWS 필요 시 검토 |
| 사용자 기록 앱 | NRC · 연동/기록 제출은 선행 조건 아님 |
| 문서 | 그림·흐름도 먼저 · 짧은 캡션 · 필요한 값만 표 |
| 관리자 | 모델 테스트/교체 · 각도·카테고리 제한 · 접속/자세/체형 통계 |
| 모델 유형 | 사용자 남성형/여성형 선택 · 기존 MPFB 원본에서 각각 제작·뼈대 재맞춤 |
| 운영 요건 | 관리자 인증·서비스 전체 통계는 운영 전 필수 · 이전 로컬 시험 보존 · 현재 관리자 진입 제거 |
| 현재 우선순위 | 문서 최우선 · 합의한 기능 시험은 병행 가능 |
| 협업 순서 | 설명 → 함께 검토 → 작은 작업 하나 → 코드와 설명 → 다음 단계 검토 |
