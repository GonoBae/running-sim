**M88 구현·검사 완료:** [선택한 코스 위 달리기](../05-validation/COURSE_RUNNING.md). 출발·방향·바퀴·기존 신체/자세를 연결하고 재생·종료를 검증했습니다.

**M87 구현 완료:** [코스 설정·화면·코드·검사](../05-validation/COURSE_SETTINGS.md). 사용자 확인을 받은 B 경로의 출발점·방향·바퀴 수를 선택하고 신체·자세를 유지합니다. M86 후보 A는 반려 이력입니다.

**M85 문서·조사 이력:** [실제 보행 좌표](../05-validation/COURSE_FEASIBILITY.md)를 확보했습니다. [화면](../03-screens/COURSE_SCREEN.md)과 [범위·순서](../04-technical/COURSE_PIPELINE.md)를 검토한 뒤 실제 한 바퀴 확정 → 코스 입력 → 기존 설정 전달 순으로 진행하는 제안입니다.

**M78 구현·검사 완료:** [네 단계 실제 화면](../05-validation/STAGE_PAGES.md). 과거 실험 화면은 이력으로 보존합니다. 코스는 M87에서 구현했고 백테스팅은 설정 요약까지 연결했습니다.

**M79 구현·검사 완료:** [신체 설정의 달리기 연결](../05-validation/BODY_RUNNING.md). 자세 입력을 유지하며 길이·전체 크기·새 발바닥 높이를 반영합니다.

**M80 구현·검사 완료:** [신체를 잡고 길이 조절](../05-validation/BODY_EDITOR.md). 신체 위 직접 조작과 화면 안 크기 손잡이를 기본 입력으로 사용합니다.

**M81 구현·검사 완료:** [다리·아래팔로 자세 조절](../05-validation/POSE_EDITOR.md). 기존 신체·기본 달리기를 유지하고 양쪽 공통 자세 값에 연결했습니다.

**M82 구현·검사 완료:** [몸통 직접 조절](../05-validation/UPPER_LEAN.md). 현재 신체·다리·팔 설정을 유지하며 상체 기울기 입력을 추가했습니다.

**M84 구현·검사 완료:** [뒤꿈치·앞꿈치 착지](../05-validation/FOOT_STRIKE.md). 기존 설정을 유지하며 착지 선택을 확장했습니다.

**M83 구현·검사 완료:** [미드풋 착지](../05-validation/MIDFOOT.md). 기존 신체·자세 설정을 유지하며 양발의 착지 직전·초반에 선택한 접촉 자세를 반영합니다.

## 단계별 증거

| 단계 | 통과 증거 | 요구 |
| --- | --- | --- |
| P0 | 확정/제안/미검증 구분 · 문서 충돌 제거 | 전체 |
| P1 | 이용 가능한 자료·지원 변수 · 실험 전 오차 기준 | R01·R02·R07·R08 |
| P2 | 입력/측정 치수·각도 · 접지 · 주기/속도 · 고정 페이스 시간 | R01–R05 |
| P3 | 참가자별 독립 평가 · 기준 모델 대비 오차 · 지원 범위 | R06–R08 |
| P4 | 같은 조건 A/B · A 보존 · 좌우 동기화 · 실패 처리 | R03–R08 |
| P5 | PC/브라우저 성능 · 비용 · 자료 권리 · 복구 절차 | R07·R08 |

P3가 성립하지 않으면 기록을 임의로 채우지 않고 원인·대안을 정리합니다. 개인 기록 저장은 후속으로 둘 수 있지만, R09–R11 관리자 권한·통계·모델 게시 연결은 P4–P5의 필수 완료 조건입니다.
