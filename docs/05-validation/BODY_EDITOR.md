신체 화면에서 부위를 드래그해 조절합니다. 정확한 범위와 입력 계약은 [M80 요구사항](../02-requirements/REQUIREMENTS.md#m80--신체-화면에서-직접-조절)에 둡니다.

## 화면과 조작

신체 위 화살표는 길이 방향, 화면 안 `전체 크기` 손잡이는 위아래 배율 조절입니다. [현재 신체 화면 열기](http://127.0.0.1:5173/body).

| 조작 | 결과 |
| --- | --- |
| 보이는 신체 부위 또는 화살표를 잡아 드래그 | 해당 부위 길이만 변경 · 양쪽 함께 적용 |
| 전체 크기 손잡이를 위아래 드래그 | 비율을 유지하며 전체 크기 변경 |
| 선택한 화살표에서 방향키 / Home·End | 미세 조절 / 최솟값·최댓값 |
| Esc / 터치 취소 / 창 이탈 | 현재 드래그 시작값으로 복원 |
| 접힌 `숫자로 미세 조절` | 기존 숫자·슬라이더 보조 입력 |

| 코드 | 역할 |

| [body-editor.ts](../../experiments/model-preview/src/body-editor.ts) | 보이는 피부 판정 → 부위 선택 → 시작점 기준 드래그 → 길이 제한·취소 |
| [stages.js](../../experiments/model-preview/src/stages.js) | 같은 신체 상태에 값 반영 / 고정된 미리보기 구도 / 다음 단계 전달 |
| [body-editor.css](../../experiments/model-preview/src/body-editor.css) | 모델 위 손잡이·치수 / 화면 안 모델 전환·초기화 / 접힌 보조 설정 |

```ts
// 드래그 시작 값 + 부위 방향으로 움직인 거리 / 화면상 부위 길이
next = clamp(id, startValue + delta.dot(axis) / pixelsPerRatio);
// 공통 신체 상태 → 기존 피부·뼈대 재구성 → 기존 자세 단계
```

**달리기 계산은 M79 그대로**입니다. 신체 길이를 바꾸는 조작이며, 관절을 굽혀 자세를 만드는 직접 조작은 별도 요구입니다.
