# 러닝 시뮬레이터 화면정의서 초안

작성일: 2026-10-02

화면 방향 확인: 2026-10-02 사용자가 이미지 시안을 보고 원하는 화면 구성임을 확인했다. 왼쪽 트랙 주행, 오른쪽 자세 상세, 두 화면에 공통으로 적용되는 재생 조작을 화면 설계 기준으로 삼는다. 색상·치수·예시 수치와 실제 트랙 형상까지 확정한 것은 아니다.

캐릭터 형태 확인: 사용자가 사람 형태의 전신 러너를 명시했다. 양쪽 화면에 동일한 전신 캐릭터를 사용한다. 관절 점과 선은 사람 모델 위에 추가하는 보조 표시다. 얼굴·복장·사실적 표현 수준은 별도 미정 사항으로 유지한다.

이 문서는 [서비스 기획서](SERVICE_PLAN.md)의 첫 버전을 화면 단위로 정의한다. 사용자가 체형과 주행 조건을 설정하고, 롯데가든파크 주변 트랙을 달리는 러너를 관찰한 뒤 다시 실행하는 흐름을 다룬다. 화면 배치, 입력 검증, 상태 전환, 버튼 동작과 표시 문구를 디자인 및 구현의 기준으로 제공한다.

실제 경로와 3D 러너를 사용하고 주변 풍경을 제외하는 것은 확인된 요구다. 사용자의 추가 요청에 따라 왼쪽에는 트랙 위를 실시간 달리는 캐릭터, 오른쪽에는 달리는 자세를 상세히 보여준다. 아래의 크기, 기본값, 조작 방식과 문구는 검토 가능한 설계 제안이다. 트랙 형상과 길이, 신체 입력 범위는 검증 전이며 이 문서의 배치도는 실제 트랙 형상을 표현하지 않는다. 앱을 구현하거나 최종 디자인을 확정한 문서가 아니다.

## 화면 이미지 시안

![캐릭터와 코스 설정 화면의 디자인을 이어받은 좌우 주행 화면 시안](images/running-dual-view-v2.png)

최신 주행 시안은 캐릭터 설정과 코스 설정의 밝은 중립색·주황색 강조·검정 버튼을 이어 사용한다. 왼쪽 트랙 주행, 오른쪽 자세 상세와 하단 공통 조작은 기존에 확인한 배치다. 이 시안의 세부 디자인은 검토 중이며 [첫 주행 시안](images/running-dual-view-v1.png)은 비교용으로 보존한다. 전체 목표 진행률과 바퀴 진행률은 구분한다. 이미지 하단의 42%는 전체 목표 대비 거리의 예시다.

내장 이미지 생성 도구로 제작한 정적 기획 시안이다. 트랙의 타원 형태와 차선, 표시 수치는 예시이며 롯데가든파크의 실제 형상이나 측정 결과가 아니다. 관절 표시는 자세 관찰 방식의 예시로, 정확한 관절 위치나 분석 결과를 검증한 그림이 아니다.

왼쪽과 오른쪽은 동일한 러너, 체형과 시뮬레이션 시점을 공유한다. 오른쪽은 러너의 위치 이동을 따라가지 않고 화면 중앙에서 현재 자세를 크게 보여준다. 동작 형태 고정 조건은 유지하며, 자세 화면 자체가 자세 교정이나 생체역학 진단을 제공하는 것은 아니다.

## 화면 목록과 이동 흐름

첫 진입은 별도의 [캐릭터 커스터마이징 화면](CUSTOMIZATION_SCREEN.md)이다. 캐릭터 확정 후 [코스 설정 화면](COURSE_SCREEN.md)에서 목표와 페이스를 정하고, 시작하면 좌우 주행 화면으로 이동한다. 실행·일시정지·완료는 같은 작업 화면에서 상태를 전환한다. 아래의 준비 화면은 전용 코스 설정 화면을 의미하며 배치는 해당 문서를 따른다. 코스 정보와 재시작 확인은 보조 창으로 연다. 로그인과 NRC 연결 화면은 첫 버전에 두지 않는다.

| 화면 | 진입 조건 | 목적 | 다음 동작 |
| --- | --- | --- | --- |
| 캐릭터 커스터마이징 화면 | 첫 접속 또는 캐릭터 수정 | 전신 캐릭터를 보며 신체 설정 | 이 캐릭터로 시작 |
| 코스 설정 화면 | 캐릭터 설정 확정 또는 주행 조건 수정 | 트랙 확인과 목표·페이스 설정 | 달리기 시작 |
| 주행 화면 | 유효한 조건으로 시작 또는 재개 | 러너와 진행 상황 관찰 | 일시정지, 재시작, 설정 변경, 목표 도달 |
| 일시정지 화면 | 정지 버튼 또는 탭 숨김 | 같은 시점에서 멈춰 관찰 | 재개, 재시작, 설정 변경 |
| 완료 화면 | 목표 거리 도달 | 실행 결과 확인 | 다시 달리기, 설정 변경 |
| 중도 종료 화면 | 설정 변경을 위해 현재 실행 종료 | 종료 시점의 기록을 구분해 표시 | 설정 편집과 새 실행 |
| 코스 정보 창 | 코스 정보 선택 | 거리 기준과 출처 확인 | 창 닫기 |
| 진행 초기화 확인 창 | 주행 도중 재시작 또는 설정 변경 선택 | 진행 기록 초기화 안내 | 취소 또는 선택한 동작 실행 |
| 로딩 및 오류 화면 | 최초 진입, 자료 실패 또는 3D 표시 실패 | 준비 상태와 복구 방법 안내 | 준비 화면 또는 재시도 |

주요 흐름은 캐릭터 설정 → 주행 준비 → 주행 → 완료다. 주행과 일시정지는 서로 오갈 수 있다. 주행 조건 변경을 확정하면 중도 종료 후 준비 화면으로 돌아간다. 캐릭터 수정은 중도 종료 후 별도 커스터마이징 화면으로 이동한다. 중도 종료 결과는 준비 화면의 접을 수 있는 요약으로 남긴다.

## 공통 배치

주행 화면의 데스크톱 기준 크기는 1440 × 900px로 제안한다. 상단은 약 64px, 하단은 공통 조작부로 두고, 중앙은 왼쪽 트랙 주행 약 60%, 오른쪽 자세 상세 약 40%로 배분한다. 고정 크기로 화면을 잘라내지 않고 창 크기에 맞춰 조정한다. 상단 설정 창에서는 주행 조건을 편집하고 체형은 요약만 표시한다. “캐릭터 수정”은 별도 커스터마이징 화면으로 이동한다.

아래 도식은 구성 요소의 상대적 위치를 보여주는 배치도다.

```text
┌────────────────────────────────────────────────────────────────────┐
│ 러닝 시뮬레이터   롯데가든파크 [코스 정보]  상태   [러너 설정]     │
├─────────────────────────────────────┬──────────────────────────────┤
│ 트랙 주행                           │ 자세 상세                    │
│ [따라가기 / 전체 보기]              │ [측면 / 정면 / 후면]         │
│                                     │ [관절 표시]                  │
│                                     │                              │
│ 실제 트랙을 이동하는 러너           │ 같은 순간의 러너 확대       │
│ 출발선과 진행 방향                  │ 상체와 팔다리의 자세 관찰   │
│                                     │                              │
├─────────────────────────────────────┴──────────────────────────────┤
│ [일시정지] [처음부터] 배속   거리 / 목표   시간   페이스   바퀴    │
└───────────────────┴────────────────────────────────────────────────┘
```

코스 설정 화면에서는 왼쪽 트랙에 확정한 러너를 정지 상태로 배치하고 오른쪽에 목표와 페이스를 표시한다. 실행 후에는 오른쪽이 자세 상세인 좌우 주행 화면으로 이동한다. 커스터마이징에서 확정한 체형은 주행의 두 화면에 함께 반영된다. 실행 중에는 설정 창에서 조건을 읽기 전용으로 확인한다. 완료 시에도 양쪽 화면을 유지하며 하단 결과 요약에서 상세 결과를 펼칠 수 있게 한다.

1024px 미만에서는 트랙 주행과 자세 상세를 탭으로 전환하는 방식을 제안한다. 데스크톱에서는 두 화면을 동시에 볼 수 있음을 안내한다. 모바일 전용 조작과 레이아웃은 첫 버전 완료 범위에서 제외한다. 3D 영역과 결과가 겹쳐 가려지는 배치는 피한다.

### 자세 상세 화면

측면을 기본으로 하고 정면·후면으로 전환할 수 있게 한다. 러너 전신이 잘리지 않도록 카메라를 배치한다. 시점 변경은 동작 진행에 영향을 주지 않는다. 관절 표시를 켜면 모델의 어깨·팔꿈치·골반·무릎·발목 기준점을 연결해 움직임을 관찰할 수 있다. 관절 정의가 확정되기 전에는 각도 수치나 정상·비정상 판정을 표시하지 않는다.

두 화면은 같은 동작 프레임과 시간을 공유한다. 일시정지하면 두 러너가 같은 순간에 멈추고, 배속을 바꾸면 함께 빨라진다. 자세 화면에 별도의 재생 버튼은 두지 않는다. 화면 오류가 발생하면 양쪽 주행을 함께 멈춘다.

## 준비 화면

### 캐릭터 설정 후 진입 상태

코스는 롯데가든파크 트랙으로 고정하며 선택 가능한 다른 코스가 있는 것처럼 드롭다운을 표시하지 않는다. 러너는 앞선 커스터마이징 화면에서 확정한 체형을 사용한다. 캐릭터 설정이 없으면 주행 준비로 바로 진입할 수 없다.

주행 기본값은 거리 목표 1.00km, 페이스 6분 00초/km, 재생 1배속을 제안한다. 기본값은 체험 예시이며 사용자 기록과 무관하다. 바퀴 수 목표로 처음 전환할 때는 1바퀴를 사용한다. 신체 기본 치수는 모델 선정 후 정한다.

### 체형 입력

아래 입력은 별도 커스터마이징 화면에 배치한다. 주행 준비에서는 편집 필드 대신 확정값 요약과 “캐릭터 수정”을 제공한다. 첫 진입·수정·취소 규칙은 [전용 화면정의서](CUSTOMIZATION_SCREEN.md)를 따른다.

| 항목 | 조작과 단위 | 표시 및 반영 | 검증 |
| --- | --- | --- | --- |
| 키 | 숫자 입력과 조절 막대, cm | 전체 높이 변경 | 양수, 모델 허용 범위, 부위 길이와의 관계 |
| 몸무게 | 숫자 입력, kg | 설정에 보관, “첫 버전에서는 체중에 따른 주행 변화가 없습니다” 안내 | 양수, 허용 범위는 별도 확정 |
| 다리 길이 | 숫자 입력과 조절 막대, cm | 다리 비율 변경 | 측정 기준과 모델 범위 적용 |
| 상체 길이 | 숫자 입력과 조절 막대, cm | 상체 비율 변경 | 측정 기준과 모델 범위 적용 |
| 어깨너비 | 숫자 입력과 조절 막대, cm | 어깨 폭 변경 | 모델 범위 적용 |
| 발 크기 | 숫자 입력과 조절 막대, mm | 발 크기 변경 | 모델 범위 적용 |

커스터마이징 화면에서 다리 길이부터 발 크기까지는 “신체 비율” 영역에 배치한다. 키·몸무게는 “기본 신체”에 표시한다. 각 치수의 설명 버튼은 측정 시작점과 끝점을 안내한다. 정확한 측정 정의가 없는 상태로 구현하지 않는다.

유효한 입력은 즉시 미리 보기에 반영한다. 빈칸이나 범위 밖 값을 편집하는 동안에는 마지막 유효한 외형을 유지하고 “입력값을 확인하면 미리 보기에 반영됩니다”라고 안내한다. 필드를 벗어나면 오류를 표시한다. 다른 부위의 값을 몰래 보정하지 않는다.

“기본 체형으로” 버튼은 커스터마이징 화면의 체형 초안만 기본 프리셋으로 되돌린다. 목표와 페이스는 유지한다. 수정한 체형은 완료 버튼으로 확정하며 주행 화면에는 이 초기화 버튼을 표시하지 않는다.

### 주행 조건

| 항목 | 형태 | 검증과 동작 |
| --- | --- | --- |
| 목표 방식 | 거리 / 바퀴 수 탭 | 하나만 활성화한다. 전환 전 각 입력값은 편집 세션 동안 기억한다. |
| 목표 거리 | 숫자 입력, km | 0보다 커야 하며 소수 둘째 자리까지 입력한다. 초과 자릿수는 안내하고 자동 반올림하지 않는다. |
| 목표 바퀴 | 숫자 입력, 바퀴 | 1 이상의 정수만 허용한다. |
| 설정 페이스 | 분·초를 나눈 숫자 입력 | 분은 0 이상 정수, 초는 0~59 정수, 합계는 0보다 커야 한다. |
| 환산 정보 | 읽기 전용 | 바퀴 목표는 총거리, 거리 목표는 대략의 바퀴 수를 코스 길이로 계산해 표시한다. |
| 예정 소요 시간 | 읽기 전용 | 목표 거리와 고정 페이스로 계산한다. 운동 능력 예측이라고 표시하지 않는다. |

거리·바퀴·페이스 상한과 체형 허용 범위는 성능 및 모델 검토 후 확정할 항목이다. 이 범위가 정해지기 전에는 첫 버전의 입력 명세가 완료된 것으로 취급하지 않는다. 코스 길이가 준비되지 않았으면 환산 정보는 “코스 거리 확인 중”으로 표시하고 시작을 막는다.

### 시작 버튼

버튼 문구는 “달리기 시작”이다. 코스와 러너가 로딩되었고 모든 입력이 유효할 때만 활성화한다. 비활성화 이유는 버튼 바로 위에 텍스트로 표시한다. 선택하면 입력 조건을 이번 실행에 고정하고 시간·거리·완료 바퀴를 0으로 초기화한 뒤 바로 주행한다. 별도 시작 확인이나 카운트다운은 두지 않는다.

## 주행 화면

실행 중 설정 창에는 체형, 코스, 목표와 페이스의 요약을 보여주고 “설정을 바꾸려면 현재 달리기를 종료해야 합니다”라는 설명과 “설정 변경” 버튼을 둔다. 창을 열 때 주행을 일시정지하고 닫은 뒤 사용자가 재개한다. 체형 입력창을 편집할 수 있는 것처럼 남겨두지 않는다.

### 주행 정보

| 표시 항목 | 형식 | 규칙 |
| --- | --- | --- |
| 누적 거리와 목표 | 0.00 / 1.00 km와 같은 형식 | 내부 계산은 원래 정밀도를 유지한다. 완료 전 표시 반올림으로 목표 도달처럼 보이지 않게 한다. |
| 경과 시간 | HH:MM:SS | 실제 대기 시간이 아닌 시뮬레이션 시간이다. 제목에 “시뮬레이션 시간”을 사용한다. |
| 페이스 | 6′00″/km와 같은 형식 | 첫 버전에서는 설정된 고정값을 표시한다. |
| 완료 바퀴 | 0바퀴 완료 | 출발선 통과를 중복 집계하지 않는다. |
| 현재 바퀴 진행률 | 0~100% 막대와 텍스트 | 다음 바퀴로 넘어가면 0%부터 다시 시작한다. 정수 바퀴 목표 완료 시 “마지막 바퀴 완료”로 표시한다. |
| 실행 상태 | 달리는 중 / 일시정지 / 완료 | 색상과 텍스트를 함께 사용한다. |

목표가 바퀴의 중간이면 완료 패널에 완료 바퀴 수와 추가 진행 거리를 구분한다. 처음 시작한 바퀴를 이미 완료한 바퀴로 세지 않는다. 칼로리·심박·피로 수치와 빈 차트는 첫 버전에서 표시하지 않는다.

### 조작부

| 조작 | 주행 중 | 일시정지 중 | 완료 후 |
| --- | --- | --- | --- |
| 일시정지 / 재개 | 위치·시간·동작을 함께 멈춘다. | 같은 위치에서 재개한다. | 표시하지 않는다. |
| 처음부터 | 초기화 확인 창을 연다. | 초기화 확인 창을 연다. | 결과 패널의 “다시 달리기”로 대체한다. |
| 배속 | 1배·2배·5배·10배를 즉시 적용한다. | 선택만 바꾸며 자동 재개하지 않는다. | 숨긴다. |
| 시점 | 따라가기 / 전체 보기 | 정지 상태에서도 전환 가능하다. | 전환 가능하다. |
| 설정 변경 | 초기화 확인 창을 연다. | 초기화 확인 창을 연다. | 확인 없이 준비 화면으로 이동한다. |

카메라 전환은 러너의 위치나 시간을 바꾸지 않는다. 따라가기에서는 러너가 화면 밖으로 벗어나지 않게 하고, 전체 보기에서는 트랙 전체와 출발선이 보이게 한다. 자유 회전·확대 조작, 구간 이동 막대와 역방향 재생은 첫 버전에서 제외한다.

배속 옆에는 “보기 속도”라는 라벨을 사용한다. 10배속을 실제 러너의 속도 증가로 오해하지 않도록 설정 페이스와 별도로 배치한다.

## 일시정지와 진행 초기화

일시정지 시 3D 화면을 가리지 않는 작은 안내에 “일시정지됨”과 “재개”를 표시한다. 탭을 벗어난 경우에는 “다른 탭으로 이동해 일시정지했습니다”라고 표시하며 돌아와도 자동 재개하지 않는다.

초기화 확인 창을 열면 먼저 주행을 일시정지한다. 취소하면 원래 주행 중이었는지 여부에 따라 재개 또는 일시정지를 유지한다. 창이 열린 동안 탭을 벗어났다면 취소 후에도 일시정지를 유지한다.

| 요청 | 제목과 설명 | 버튼 | 확정 후 |
| --- | --- | --- | --- |
| 처음부터 | “처음부터 다시 달릴까요?” / “현재 진행 기록이 초기화됩니다. 체형과 주행 조건은 유지됩니다.” | 취소 / 처음부터 달리기 | 같은 실행 조건으로 거리와 시간을 0으로 초기화하고 시작한다. |
| 설정 변경 | “달리기를 종료하고 설정을 바꿀까요?” / “지금까지의 기록은 중도 종료로 표시됩니다.” | 취소 / 종료하고 설정 변경 | 중도 종료 요약을 남기고 입력값을 유지한 준비 화면으로 돌아간다. |
| 캐릭터 수정 | “달리기를 종료하고 캐릭터를 수정할까요?” / “지금까지의 기록은 중도 종료로 표시됩니다.” | 취소 / 종료하고 캐릭터 수정 | 중도 종료 요약과 주행 조건을 유지하고 별도 커스터마이징 화면으로 이동한다. |

재시작과 완료 후 다시 달리기는 카메라 선택은 유지하되 보기 속도는 1배로 되돌린다. 일반 일시정지 후 재개는 기존 배속을 유지한다.

## 완료와 중도 종료 결과

완료되면 목표 위치에서 러너를 멈추고 오른쪽 자세도 같은 순간에서 멈춘다. 하단에 “달리기 완료” 요약과 상세 결과 펼치기를 표시한다. 불필요한 전체 화면 전환은 하지 않는다.

| 결과 요소 | 내용 |
| --- | --- |
| 실행 요약 | 코스 이름, 목표 방식과 값, 설정 페이스 |
| 결과 | 진행 거리, 시뮬레이션 소요 시간, 완료 바퀴와 추가 거리 |
| 체형 상세 | 이번 실행에 사용한 각 치수와 단위, 접어서 표시 가능 |
| 코스 상세 | 코스 정보 창에서 출처와 버전 확인 |
| 안내 | “설정한 페이스로 달린 결과입니다.” |
| 다음 행동 | 다시 달리기 / 설정 변경 |

“다시 달리기”는 완료한 조건을 그대로 사용한다. “설정 변경”은 기존 값을 채운 준비 화면으로 돌아간다. 직전 결과는 접힌 요약으로 남기고 새 달리기를 시작하면 대체한다. 여러 실행의 저장 목록은 제공하지 않는다.

중도 종료 요약의 제목은 “달리기 중도 종료”다. 목표와 실제 진행 거리를 함께 표시하고 완주 시간이라는 표현은 쓰지 않는다. 새로고침 후 설정과 결과 유지가 보장되지 않음을 결과 요약 하단에 “현재 기록은 이 페이지에서만 유지됩니다”로 안내한다.

## 코스 정보 창

주행 중 열면 일시정지한다. 닫은 뒤에는 주행이 자동 재개되지 않으며 재개 버튼을 통해 이어간다. 준비·완료 상태에서는 원래 상태를 유지한다.

| 항목 | 표시 규칙 |
| --- | --- |
| 이름 | 롯데가든파크 주변 트랙 |
| 한 바퀴 길이 | 채택한 경로의 길이와 단위, 근사값이면 “약” 표시 |
| 거리 기준 | 어떤 주행 선을 따라 산정했는지 설명 |
| 출발점과 방향 | 자료로 확인한 설명과 단순 경로 그림 |
| 고도 | 고도 반영 / 평면화 중 실제 적용된 방식을 표시 |
| 자료 출처 | 사용 자료의 이름, 필요한 출처 링크와 표기 |
| 코스 버전 | 실행에 사용한 경로 버전과 작성 또는 갱신 날짜 |

현재 미확인 값은 문서와 검토 화면에서 “미확인”으로 남긴다. 공개 버전에는 검증한 경로가 있어야 하며, 코스가 없는 상태에서 원형 트랙을 실제 장소의 경로로 표시하지 않는다. 제공자 출처 표기가 상시 필요한 경우 창 안에만 숨기지 않고 해당 조건에 맞춰 화면에 노출한다.

## 로딩과 오류 표시

| 상황 | 표시 문구 | 처리 |
| --- | --- | --- |
| 최초 준비 | “트랙과 러너를 불러오는 중입니다” | 시작 비활성화, 실제 진행률을 모르면 임의 퍼센트 미표시 |
| 잘못된 거리 | “목표 거리는 0보다 큰 숫자로 입력해 주세요” | 해당 입력 바로 아래 표시 |
| 잘못된 바퀴 | “바퀴 수는 1 이상의 정수로 입력해 주세요” | 해당 입력 바로 아래 표시 |
| 잘못된 페이스 | “분과 초를 확인해 주세요. 초는 0~59로 입력합니다” | 페이스 묶음 아래 표시 |
| 체형 범위 초과 | “이 모델에서 사용할 수 있는 범위는 {최솟값}~{최댓값}{단위}입니다” | 실제 확정 범위로 치환하며 시작 차단 |
| 체형 조합 충돌 | “키와 부위 길이의 조합을 확인해 주세요” | 문제가 되는 필드를 함께 표시하고 구체 조건 추가 |
| 자료 로딩 실패 | “트랙 또는 러너를 불러오지 못했습니다” | 다시 시도 버튼, 입력한 설정 유지 |
| 코스 거리 누락 | “코스 거리 정보가 준비되지 않아 시작할 수 없습니다” | 시작 차단, 자료 재시도 제공 |
| 3D 초기화 실패 | “이 환경에서 3D 화면을 시작하지 못했습니다” | 새로고침 안내, 실제 검증된 지원 환경 안내 |
| 주행 중 화면 오류 | “화면에 문제가 발생해 달리기를 멈췄습니다” | 시간도 정지, 복구되면 명시적 재개, 불가능하면 처음부터 안내 |

오류를 닫기 어려운 알림창으로 반복 표시하지 않는다. 입력 오류는 수정 후 해소하고, 여러 오류가 있으면 첫 오류로 이동할 수 있게 한다. 3D 화면이 멈춘 동안 주행 시간만 계속 증가하지 않게 한다.

## 접근성과 표시 원칙

- 입력마다 항목명과 단위를 항상 보여준다. 안내 문구만으로 라벨을 대신하지 않는다.
- 버튼, 목표 방식, 배속과 시점은 키보드로 선택 가능하게 한다. 선택과 포커스를 색상 외 테두리·텍스트로 구분한다.
- 확인 창은 제목을 읽을 수 있게 하고 창 안에서 포커스를 이동한다. 닫으면 호출한 버튼으로 포커스를 돌린다. Escape는 취소 또는 닫기와 같다.
- 진행 수치가 계속 바뀔 때 화면 읽기 도구가 매 순간 알리지 않게 한다. 시작·일시정지·완료와 오류 등 상태 변화만 안내한다.
- 화면 움직임을 줄이고 싶은 사용자는 전체 보기로 전환할 수 있다. 카메라 전환에 불필요한 회전 효과를 넣지 않는다.
- 구현용 식별자, 내부 계산 단위와 디버그 정보는 일반 화면에 표시하지 않는다.

## 첫 버전에서 제외하는 화면

계정과 프로필 관리, NRC 인증, 임의 경로 편집, 기록 목록과 공유, 두 실행 동시 비교, 에너지·심박·피로 분석, 실제 풍경 설정은 후속 범위다. 사용할 수 없는 메뉴를 첫 화면에 나열하지 않는다. 이 제외는 장기 기획에서 기능을 삭제한다는 뜻이 아니다.

## 화면 검토 완료 기준

| 검토 항목 | 확인할 내용 |
| --- | --- |
| 시작 가능성 | 처음 접속해 캐릭터를 설정·확정하고 주행 준비로 이동하는 방법을 알 수 있다. |
| 입력 반영 | 유효한 체형 변경이 보이고 무효 입력은 원인과 해결 방법을 알 수 있다. |
| 공간 이해 | 전체 보기에서 실제 트랙 형태, 출발선과 러너 위치를 구분할 수 있다. |
| 주행 관찰 | 따라가기 시점에서 러너가 보이고 진행 정보가 가리지 않는다. |
| 자세 관찰 | 오른쪽 러너 전신이 보이고 측면·정면·후면을 전환할 수 있다. |
| 동시 재생 | 두 화면의 체형과 동작 시점이 일치하며 일시정지·배속·재개가 함께 적용된다. |
| 상태 이해 | 주행·일시정지·완료·중도 종료를 문구만으로 구분할 수 있다. |
| 시간 이해 | 배속을 바꿔도 설정 페이스와 시뮬레이션 소요 시간이 바뀌지 않음을 알 수 있다. |
| 재실행 | 완료 후 같은 조건 또는 바꾼 조건으로 시작할 수 있다. |
| 오류 복구 | 로딩 실패와 화면 오류 시 다시 시도하거나 설정으로 돌아갈 수 있다. |
| 기획 일치 | 실제 풍경, NRC 연동, 미검증 생리 수치를 필수 기능처럼 보여주지 않는다. |

구현 전에 남은 세부 결정은 모델별 치수 기준과 입력 범위, 코스의 정확한 주행 선·길이·출발점·방향, 지원 브라우저와 화면 성능 기준이다. 실제 화면의 가독성과 동작 검증은 후속 디자인 및 구현 단계에서 수행한다.
