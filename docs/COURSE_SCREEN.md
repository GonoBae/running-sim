# 코스 설정 화면정의서

작성일: 2026-10-02

검토 상태: 사용자는 첫 코스 시안에 대해 “일단 오케이”라고 응답하고 다음 단계 진행을 요청했다. 현재 배치와 디자인 방향으로 다음 화면을 진행하되 실제 경로 데이터와 세부 기능까지 확정된 것으로 보지는 않는다.

캐릭터 설정 다음 단계에서 코스를 확인하고 목표와 페이스를 정하는 전용 화면이다. 현재 캐릭터 시안의 밝은 중립색, 주황색 강조와 검정 버튼을 이어 사용한다. 세부 배치와 조작은 검토용 제안이며 실제 코스 자료는 확보 전이다.

## 화면 시안

![트랙 미리 보기와 목표 및 페이스 설정 화면](images/course-setup-v1.png)

내장 이미지 생성 도구로 만든 정적 시안이다. 경로의 굴곡·폭·차선·출발점·방향은 실제 롯데가든파크 측량값이 아니며 예시다. 한 바퀴 거리는 미확인으로 표시했다. 공개 구현에서는 검증한 자료가 준비되기 전 시작을 막는다. 시안의 검정 시작 버튼은 시각 디자인 예시다.

## 화면 흐름

캐릭터 설정 → 코스 설정 → 시뮬레이션 순서로 구성한다. 주소는 `/`, `/course`, `/run`으로 나누는 안을 제안한다. 캐릭터 미확정 상태에서 뒤 단계에 접근하면 캐릭터 화면으로, 캐릭터는 있으나 주행 조건이 미확정이면 코스 화면으로 안내한다.

“이 캐릭터로 시작”은 코스 설정으로 이동한다. “달리기 시작”은 검증된 실행 조건을 고정하고 좌우 주행·자세 화면으로 이동해 실행한다. 기존의 같은 주행 화면에서 준비와 실행을 처리하는 안을 전용 코스 화면으로 대체한다.

## 배치

| 영역 | 내용과 동작 |
| --- | --- |
| 상단 | 코스 설정과 02 / 03으로 현재 단계 표시 |
| 왼쪽 안내 | 02 — ROUTE, 코스와 목표 안내를 캐릭터 화면과 같은 위치에 정렬 |
| 왼쪽 미리 보기 | 트랙 전체, 출발점, 진행 방향과 설정한 캐릭터를 표시. 주변 풍경 제외 |
| 미리 보기 하단 | 전체 보기, 출발점 보기, 확대·축소·시점 초기화. 경로 자체는 바꾸지 않음 |
| 오른쪽 위 | 롯데가든파크 주변 트랙, 한 바퀴 거리, 코스 정보. 첫 버전은 한 코스 |
| 오른쪽 중간 | 거리 또는 바퀴 수와 설정 페이스 편집 |
| 오른쪽 아래 | 목표 거리와 예정 소요 시간의 읽기 전용 요약 |
| 주요 버튼 | 달리기 시작으로 실행 화면 이동 |
| 보조 버튼 | 캐릭터 수정으로 이전 화면 복귀, 주행 조건 초안 유지 |

## 입력과 계산

거리 목표는 km 단위 숫자 입력으로 소수 둘째 자리까지 허용한다. 1·3·5·10km는 빠른 선택값 제안이다. 바퀴 수는 1 이상의 정수로 입력한다. 목표 방식 전환 전 값을 기억하되 선택한 방식만 실행에 적용한다.

증감 버튼의 제안 단위는 거리 0.1km, 바퀴 1바퀴, 페이스 5초/km다. 직접 입력은 더 세밀한 값도 허용하며 양수 여부와 페이스 초 0~59 등의 검증을 적용한다. 최댓값·최솟값은 성능과 모델 검토 후 확정한다.

페이스는 분과 초로 입력한다. 예정 소요 시간은 고정 페이스 × 목표 거리다. 시안의 1.00km와 6분/km는 6분 00초다. 개인의 실제 완주 능력 예측이나 사용자의 기록이 아니다.

한 바퀴 거리가 없으면 바퀴 목표를 거리로 환산하지 않고 확인 예정으로 표시한다. 거리 목표여도 검증된 경로가 준비되지 않으면 시작할 수 없다. 코스가 평면화되었으면 정보 창에 표시한다. 출발점 변경, 역방향 선택, 경로 편집과 다른 코스 추가는 첫 시안에 포함하지 않는다.

## 상태와 돌아오기

자료 로딩 중에는 상태를 표시하고 시작을 막는다. 자료 실패는 재시도를 제공하고 입력한 조건을 유지한다. 입력 오류는 해당 항목 옆에 표시한다. 캐릭터와 코스가 준비되고 입력이 유효하면 시작할 수 있다.

캐릭터 수정 후 다시 오면 목표와 페이스를 유지한다. 주행 중 조건 변경은 실행 종료 확인을 거쳐 이 화면으로 돌아오며 중도 종료 기록을 접힌 요약으로 제공한다. 완료 후 조건 변경도 이 화면으로 돌아온다. 새 실행 시 직전 실행 요약을 대체한다. 장기 저장은 후속 범위다.

## 검토 기준

- 첫 캐릭터 설정 화면의 시각적 흐름이 유지된다.
- 코스와 진행 방향, 출발점을 알아볼 수 있다.
- 실제 경로 미확인 상태와 실행 가능한 상태를 구분한다.
- 거리·바퀴 목표와 페이스 입력의 단위가 명확하다.
- 예정 소요 시간이 입력과 일치한다.
- 캐릭터 수정과 실행 화면 이동 시 설정이 유지된다.
