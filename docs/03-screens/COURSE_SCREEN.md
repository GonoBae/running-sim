# 코스 세팅

2026-10-22 · v0.14 / M93 · **항공사진 대조·전후 비교 구현 / 현장 도착점 전체 일치 미해결**

![수정 경로와 수정 전 도착점 비교 실제 구현 화면](../assets/images/course-imagery-map-4km.png)

항공사진에서 확인한 광장 우회를 제거한 D 경로로 계산합니다. 주황 점선은 수정 전 경로·도착점이며 비교 표시를 꺼도 설정은 유지됩니다.

| 영역 | 구현 동작 |
| --- | --- |
| 지도 | 수정 D 경로 · 출발·도착·방향 · 수정 전 경로/도착점 점선 |
| 지도 아래 | 항공사진 대조 정보·한 바퀴 전후 길이·비교 표시 전환 · 기존 입력 |
| 러너 | 기존 신체·자세 유지 · 정면·측면·재생 |
| 자료 변경 | 오류 원본 미적용 · 최신 원본 조회는 수집 명령 / 화면은 검증 자산 사용 |

[현재 검사·코드](../05-validation/COURSE_IMAGERY.md) · [M91 철회 이력](../05-validation/COURSE_CALIBRATION.md). 아래 그림은 M87–M90 구현 이력입니다.

## 상태와 이동

![입력·기존 러너·임시 저장·오류 차단](../assets/diagrams/course-settings.svg)

자료 오류는 재시도, 출발 미선택·입력 오류는 설명과 다음 단계 차단으로 표시합니다. 이전/다음/새로고침 후 설정 유지 결과는 [M87 검사](../05-validation/COURSE_SETTINGS.md)에 있습니다.

정확한 계약은 [항공사진 수정 M93](../02-requirements/REQUIREMENTS.md#m93--항공사진-대조와-경로-오류-수정)·[자동 검증 M92](../02-requirements/REQUIREMENTS.md#m92--코스-자동-계산과-원본-검증)·[페이스 M90](../02-requirements/REQUIREMENTS.md#m90--목표-페이스와-소요-시간)·[거리 M89](../02-requirements/REQUIREMENTS.md#m89--목표-거리와-도착점)에서 관리합니다. [M85 v2 시안](../assets/images/course-screen-v2.png)은 이전 설계 이력입니다.

## 코스 주행 · M88

![왼쪽 코스 주행·오른쪽 같은 시점 자세](../assets/images/course-running-side.png)

선택한 출발점에서 방향·목표 거리대로 이동하며 목표에서 종료합니다. [정면·전체 보기·모바일·영상·코드·검사](../05-validation/COURSE_RUNNING.md)에서 실제 동작을 확인합니다.

| 영역 | 화면 동작 |
| --- | --- |
| 왼쪽 | 코스 위 러너 따라가기 / 전체 보기 · 출발점·도착점·현재 위치도 |
| 오른쪽 | 같은 시점의 자세 · 정면/측면 · 기존 신체·자세 요약 |
| 아래 | 이동 거리·완료 바퀴·재생 시간 · 재생/정지·처음부터·위치 이동·배속 |
| 상태 | 준비 후 재생 대기 → 재생/정지 → 완료 → 다시 재생 · 오류는 차단/재시도 |

정확한 단위·시간·보관 계약은 [M88 요구사항](../02-requirements/REQUIREMENTS.md#m88--설정한-실제-코스-주행)을 따릅니다. 속도는 기존 동작 재생용이며 기록 예측이 아닙니다.

## 후속 실행 방식 · 기존 제안 보존

![고정 페이스와 같은 노력 조건의 차이](../assets/diagrams/comparison.svg)

기존 v0.4의 고정 페이스 재생·같은 노력 조건 비교는 후속 설계입니다. 첫 코스 설정에서 예상 기록이나 자세 효과를 임의로 계산하지 않습니다.

| 구분 | 고정 페이스 | 같은 노력 조건 |
| --- | --- | --- |
| 입력 제안 | 양수 거리/바퀴 · 분/km · 초 0–59 | 능력·노력 정의와 모델 지원 범위 확정 후 |
| 시작 전 | 설정 페이스 기준 소요 시간 | 준비 상태 · 계산 전 기록 없음 |
| 시작 후 | 실행 자료 준비 → 재생 | 계산 → 결과 준비 → 재생 |
| 비교 | 같은 거리·페이스는 같은 시간 | 자세 A/B 예상 기록 · 별도 계산 검증 필요 |

기존 비교 요구 R08은 유지합니다. A/B 공통 조건과 실패 시 A 보존 규칙은 [요구사항](../02-requirements/REQUIREMENTS.md)·[기획서](../01-planning/SERVICE_PLAN.md)를 따릅니다.
